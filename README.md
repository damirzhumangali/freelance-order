# Orbit

Площадка для поиска заказов на сайты и приложения, с анимированной 3D-главной, фильтрами, избранным и приёмом собственных заявок.

## Дизайн

Оформление вдохновлено Belgrade Arbor: полноэкранная оригинальная 3D-сцена, лесная и песочная палитра, плавающее меню, крупная редакционная типографика, мягкий параллакс. Используются открытые шрифты Cormorant Garamond и Manrope; лицензии находятся в `public/fonts/`. Изображение и данные о его создании — в `public/images/`. Заказы, серверные API и модерация сохранены.

Прокрутка управляет короткой закреплённой сценой: камера приближается, смещается и слегка поворачивает кадр, затем он сужается и мягко переходит к описанию платформы и заказам. Используется нативная прокрутка и `requestAnimationFrame`, без перехвата колеса/касания. На мобильных последовательность короче; при `prefers-reduced-motion` и небольшой высоте окна отображается обычный поток страницы. Меню и ссылки на проекты доступны на любом этапе.

## Запуск

Требуется Node.js 22.13+.

```sh
npm ci
npm run dev
```

Локальный адрес выводится в терминале (обычно http://127.0.0.1:5173).

## Заявки и администрирование

Форма «Разместить заказ» сохраняет заявку в Cloudflare D1. До проверки описание и контакты доступны только администратору. Публикация требует согласия клиента. Статусы: новая, на проверке, опубликована, закрыта. Закрытые заявки исчезают из публичной ленты.

Панель: `/admin`. Вход через ChatGPT; сервер допускает только адреса из переменной окружения `ADMIN_EMAIL` (список через запятую). Она настроена в Sites для владельца. В локальной разработке предусмотрен тестовый вход через `/signin-with-chatgpt?return_to=/admin`; тестовая идентичность не действует в сборке для публикации.

API: `POST /api/requests`, `GET /api/orders`, `GET /api/session`, `GET /api/admin/requests`, `PATCH /api/admin/requests/:id`. Сервер проверяет происхождение запросов, поля, согласие и ограничивает число отправок с одного IP.

## Внешние заказы

`lib/external-orders.ts` — четыре реальные публикации, вручную проверенные 20 октября 2026 года. Это сохранённая подборка, а не автоматически обновляемая лента. В каждой карточке есть оригинал, дата проверки и условия связи. Freelance.ru требует Premium; Freelancehunt — аккаунт на площадке. Прямые контакты не придуманы. Содержание и статус нужно перепроверять в оригиналах при обновлении подборки.

Избранное сохраняется только в браузере пользователя; заявки хранятся на сервере.

## База данных

Привязка `DB` объявлена в `.openai/hosting.json`. Схема — `db/schema.ts`, миграции — `drizzle/`. Развёртывание Sites применяет миграции к отдельной рабочей базе.

После первой сборки локальная база инициализируется:

```sh
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_cynical_vertigo.sql
```

## Проверки

```sh
npx tsc --noEmit
npm run build
```

Проверены 36 сценариев API, включая авторизацию, приватность новых заявок, публикацию и закрытие, запрет публикации без согласия, невалидные запросы и ограничение отправок. Временные тестовые записи удалены из локальной базы. Интерфейс проверен в браузере: фильтрация, поиск, избранное, карточки заказов и форма.

Сайт первоначально развёрнут с приватным доступом владельца. Для приёма заявок от любых посетителей нужно открыть публичный доступ в настройках Sites.
