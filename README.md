# Orbit

Площадка для поиска заказов на сайты и приложения, с анимированной 3D-главной, прямым переходом к заказам, фильтрами, избранным и приёмом собственных заявок. Карточки плавно появляются при входе в экран; уже просмотренные карточки сохраняют видимость при фильтрации. При отключённой анимации или JavaScript заказы видны сразу.

## Дизайн

Оформление вдохновлено Belgrade Arbor: полноэкранная оригинальная 3D-сцена, лесная и песочная палитра, плавающее меню, крупная редакционная типографика, мягкий параллакс. Используются открытые шрифты Cormorant Garamond и Manrope; лицензии находятся в `public/fonts/`. Изображение и данные о его создании — в `public/images/`. Заказы, серверные API и модерация сохранены.

Мобильная версия рассчитана на ширины от 320 px: компактная навигация с безопасными отступами, читаемые поля 16 px, кнопки от 44 px, категории над списком и фильтры в диалоговой панели. До 1050 px боковая колонка скрывается; до 680 px карточки идут в одну колонку. Бюджет и примечание о валюте разделены, длинные названия сокращаются только в списке и полностью видны в деталях. Форма, карточка проекта и админ-панель адаптированы для телефона; закрытие формы доступно при прокрутке. Горизонтальная ориентация и режим уменьшенной анимации сохраняют доступ к действиям. Реальная 3D-сцена и автоматическая лента сохранены.

Прокрутка управляет настоящей WebGL-сценой на Three.js: отдельные бронзовые орбиты вращаются, а перспективная камера обходит скульптуру и проходит через её центр. Освещение, отражения, перекрытие колец и их ракурсы рассчитываются в реальном времени. Фоновый двор очищен от нарисованных колец; фотография со скульптурой остаётся запасным вариантом для устройств без WebGL. При уходе сцены за экран и скрытии вкладки рендер приостанавливается. Используется нативная прокрутка и `requestAnimationFrame`, без перехвата колеса/касания. На мобильных последовательность короче; при `prefers-reduced-motion` и небольшой высоте окна отображается обычный поток страницы. Меню и ссылки на проекты доступны на любом этапе.

На телефоне превью заказа компактное: название до двух строк, бюджет, срок, источник и кнопка «Смотреть проект». Описание и теги остаются в полном просмотре. Высота карточки определяется содержимым; кнопки сохраняют область нажатия от 44 px. Режимы сетки и списка используют одинаковый компактный вид до 680 px.

## Запуск

Требуется Node.js 22.13+.

```sh
npm ci
npm run dev
```

Локальный адрес выводится в терминале (обычно http://127.0.0.1:5173).

## Заявки и администрирование

Форма «Разместить заказ» сохраняет заявку в Cloudflare D1. До проверки описание и контакты доступны только администратору. Публикация требует согласия клиента. Статусы: новая, на проверке, опубликована, закрыта. Закрытые заявки исчезают из публичной ленты.

Панель: `/admin`. Вход через ChatGPT; сервер допускает только адреса из переменной окружения `ADMIN_EMAIL` (список через запятую). Она настроена в Sites для владельца. В локальной разработке предусмотрен тестовый вход через `/signin-with-chatgpt?return_to=/admin`; тестовая идентичность не действует в сборке для публикации.

API: `POST /api/requests`, `GET /api/orders`, `GET /api/session`, `GET /api/admin/requests`, `PATCH /api/admin/requests/:id`. Сервер проверяет происхождение запросов, поля, согласие и ограничивает число отправок с одного IP.

## Внешние заказы

`lib/external-orders.ts` хранит ручную подборку из 4 запросов открытого Telegram-канала «Удалёнка — вся творческая работа». Даты публикаций — 16–19 октября 2026 года, последняя ручная проверка — 20 октября. Для каждого запроса приведены номер пункта, оригинал и публичный контакт. Страна и бюджет неизвестны. Telegram и закрытые бизнес-чаты автоматически не просматриваются.

Astana Hub подключён как автоматический источник. Orbit проверяет открытые HTML-страницы раздела `https://astanahub.com/ru/tech_task/?status=success` с нативной пагинацией и отбирает запросы на сайты, веб-приложения, мобильные приложения и ботов с веб-админкой. Не используются закрытые API, вложения или скрытые контакты. Карточка содержит короткую фактическую справку и ссылку на полное ТЗ в источнике. Число предложений показывается открыто; отправка решения требует аккаунта Astana Hub. Даты публикации не выдумываются: источник их не предоставляет. «Только РК» отображается как ограничение источника, а не адрес заказчика. Валюта не подставляется, если она не названа.

`GET /api/orders` возвращает собственные опубликованные заявки, `externalOrders` и состояние `sources.astanaHub`. При обычном чтении используется кеш на час; плановая проверка обновляет его независимо от границы этого срока. Повторные сервисные запуски ограничены паузой 5 минут, параллельные запросы объединены серверной блокировкой. Результат хранится в D1 и повторно используется всеми посетителями. Открытая вкладка запрашивает данные раз в минуту и после возвращения на страницу; новые карточки появляются без сброса фильтров и избранного. Первая загрузка не считается поступлением новых заказов. Закрытые и просроченные задачи скрываются; указанная в источнике дата приёма включена целиком по времени Казахстана. При ошибке источника сохраняется предыдущая подборка, кроме уже просроченных задач, и выводится статус ошибки.

Для проверки при закрытом сайте используется связанная облачная задача Sites с часовым расписанием, Asia/Almaty. Она вызывает встроенный `POST /api/sources/astana-hub/sync` и проверяет сохранённые данные через `GET /api/orders`; перепубликация исходников для новых заказов не нужна. Endpoint принимает только фиксированный источник, без произвольных URL или данных от вызывающего. Он опирается на текущую приватную границу доступа Sites и не предназначен для публичного доступа. Перед изменением аудитории нужно отдельно защитить сервисный запуск. Текущий сервисный доступ облачный запуск получает через Sites; токены не хранятся в коде, файлах, URL или тексте расписания.

Все 15 прежних карточек Freelance.ru, FL.ru и Freelancehunt удалены по просьбе владельца. Компании без сайта, реклама разработчиков, отзывы о выполненных работах и постоянные вакансии не считаются заказами. Отсутствие других откликов не обещается.

Избранное сохраняется только в браузере пользователя; заявки хранятся на сервере.

## База данных

Привязка `DB` объявлена в `.openai/hosting.json`. Схема — `db/schema.ts`, миграции — `drizzle/`. Развёртывание Sites применяет миграции к отдельной рабочей базе.

Новые SQL-миграции применяются локально по одному разу. Для этой версии к существующей базе добавляется:

```sh
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0001_strong_mad_thinker.sql
```

## Проверки

```sh
node --experimental-strip-types --test scripts/test-astana-feed.mjs
npx tsc --noEmit
npm run build
```

Проверены 36 сценариев API, включая авторизацию, приватность новых заявок, публикацию и закрытие, запрет публикации без согласия, невалидные запросы и ограничение отправок. Временные тестовые записи удалены из локальной базы. Интерфейс проверен в браузере: фильтрация, поиск, избранное, карточки заказов и форма. Для Astana Hub проходят 6 тестов парсера/сбора: срок включительно, классификация, поля источника, изменения разметки, пагинация, дубликаты и сбои. Живая локальная проверка загрузила 11 задач в D1, подтвердила чтение сохранённых строк, отсутствие повторной загрузки при трёх параллельных POST, отказ на GET и межсайтовый POST. В браузере проверены фильтр источника, поиск и условия исходной заявки.

Сайт первоначально развёрнут с приватным доступом владельца. Для приёма заявок от любых посетителей нужно открыть публичный доступ в настройках Sites.
